# 保险复利/单利计算器

这是一个无登录、纯前端的保险收益试算工具，适合快速输入：

- 缴费年限
- 每年缴费金额
- 总交保费（可选）
- 某一年的总收益
- 该收益对应的年份

软件会自动生成未来 50 年的年化单利与复利试算表。

## 使用方式

1. 打开 `index.html`
2. 输入参数
3. 点击“计算”
4. 查看表格结果

## 说明

- 如果“总交保费”为空，程序会自动按：`缴费年限 × 每年缴费金额` 计算。
- 单利按你给定规则处理：
  - `年化单利率 = （某年总收益 - 总投入）/年份 / 总投入`
- 复利按年化复利方式反推：
  - `累计本息 = 总投入 × (1 + r)^n`
  - 因此用该年收益来反推年化复利率 `r`。

## 文件结构

- `index.html`：主页面
- `styles.css`：样式
- `app.js`：计算逻辑

## 运行环境

本软件无需安装任何依赖，直接在浏览器中打开即可。
