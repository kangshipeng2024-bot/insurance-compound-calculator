# 保险收益试算软件

这是一个无需登录、纯前端的保险收益试算工具，支持：

- 缴费年限
- 每年缴费金额
- 总交保费（可选）
- 某一年的总收益
- 该收益对应的年份

软件会自动生成未来 50 年的收益试算表，并显示：

- 年化单利率
- 年化复利率
- 单利累计本息
- 复利累计本息

## 使用方式

1. 打开 `index.html`
2. 输入相关参数
3. 点击“计算”
4. 如果需要，可点击“导出 CSV”保存结果

## 说明

- 若“总交保费”为空，会自动按：`缴费年限 × 每年缴费金额` 计算。
- 单利按你给定规则计算：
  - `年化单利率 = （某年总收益 - 总投入）/年份 / 总投入`
- 复利按年化复利形式反推：
  - `累计金额 = 总投入 × (1 + r)^n`

## 文件结构

- `index.html`：主页面
- `styles.css`：样式文件
- `app.js`：计算及导出逻辑

## 运行方式

直接在浏览器中打开 `index.html` 即可，不需要安装任何依赖。
